# Plan de Lanzamiento Inicial (`v0.1.0`) y Publicación en GitHub

## 1. Propuestas de Nombre para el Proyecto (Reemplazando `master`)

Actualmente el paquete en `Cargo.toml` se llama `master` y el bundle `VolumeMixer.app`. Para publicarlo en GitHub como proyecto open-source en Rust, estas son las mejores opciones:

| Nombre | Identificador (`Bundle ID`) | Por qué encaja |
| :--- | :--- | :--- |
| **1. `Onda` (Recomendado)** | `com.onda.mixer` / `Onda.app` | Corto, fácil de recordar en español e inglés, hace referencia directa a las ondas de sonido y al icono del tray (`\|┃\|┃\|`). |
| **2. `Fader`** | `com.fader.mixer` / `Fader.app` | Nombre técnico de los deslizadores de una consola de mezcla de estudio; suena muy nativo en macOS. |
| **3. `Sonora`** | `com.sonora.audio` / `Sonora.app` | Elegante, con personalidad propia para una app de audio en macOS. |
| **4. `Klang`** | `com.klang.mixer` / `Klang.app` | Minimalista ("sonido/timbre" en alemán), estilo herramientas modernas en Rust. |

## 3. Pasos para Publicar `v0.1.0` en GitHub

```bash
# 1. Compilar versión optimizada de producción (Release)
./scripts/bundle_app.sh release

# 2. Crear commit inicial y tag v0.1.0
git add .
git commit -m "feat: initial v0.1.0 MVP release (GPUI + Core Audio Process Tap + 10-band EQ)"
git tag -a v0.1.0 -m "Release v0.1.0"

# 3. Crear el repositorio en GitHub (usando GitHub CLI o web) y subir código + tag
gh repo create onda --public --source=. --remote=origin --push
git push origin v0.1.0
```

## 4. Roadmap Post-`0.1.0` (Futuras Actualizaciones)

1. **`v0.2.0` — Productividad y Entrada de Audio:**
   - **Atajos globales de teclado** reales en segundo plano (subir/bajar app activa, mutear app en foco, abrir/cerrar popover).
   - **Control de micrófono (Input):** Slider de ganancia y botón de mute para el micrófono predeterminado.
   - **Auto-Ducking:** Bajar automáticamente el volumen de música (Spotify/Apple Music) cuando entra audio de voz (Discord/Zoom).
2. **`v0.3.0` — Perfiles de Audio y Grabación Rápida:**
   - **Perfiles personalizados de Ecualizador:** Guardar, renombrar y exportar curvas de EQ propias.
   - **Restauración automática al cerrar (`Drop` global):** Garantizar limpieza de preferencias temporales si `restore_on_close` está activo.
   - **Icono `.dmg` con arrastrar a `/Applications`.**
3. **`v1.0.0` — Distribución Masiva:**
   - Publicación en **Homebrew Tap** (`brew install --cask onda`).
   - Firma con certificado Apple Developer ID + Notarización para evitar el aviso de Gatekeeper al descargar de internet.
