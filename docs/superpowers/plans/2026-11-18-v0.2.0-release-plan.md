# Onda v0.2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the three `v0.2.0` roadmap features — Per-Input Microphone Control, Auto-Ducking, and Global Keyboard Shortcuts — and prepare the `v0.2.0` release.

**Architecture:** All audio hardware discovery and DSP state stay behind `AudioBackend` + `AudioEngine` (`src/audio/mod.rs`), with Core Audio FFI isolated in `src/audio/master.rs`, pure state models and serde persistence in `src/state.rs`, and GPUI views reading `MixerSnapshot` in `src/ui/popover/`. Global hotkeys use `global-hotkey` (Carbon `RegisterEventHotKey` on macOS, requiring no Accessibility permission) integrated into the 16ms event loop in `src/main.rs`.

**Tech Stack:** Rust (2024 edition), GPUI `0.2.2`, `objc2-core-audio` / `objc2-app-kit`, `serde` / `serde_json`, `global-hotkey`

## Global Constraints

- Platform floor: macOS 14.2+ (`LSMinimumSystemVersion` = `14.2`).
- Rust edition: `2024`; clippy lints `all` and `redundant_clone` are `warn`, `nonstandard_style` is `deny`.
- Core Audio FFI must remain inside `src/audio/` (never leak raw `AudioObjectID` property calls into UI modules).
- All `Preferences` additions must use `#[serde(default)]` so existing `~/Library/Application Support/Onda/volumes.json` files deserialize cleanly.
- Auto-ducking must scale the tap's effective gain (`config.volume * duck_multiplier`) without mutating the user's stored `AppVolumeConfig.volume`.
- Every task must end with `cargo test --lib` passing (note: 4 `updater::tests` bind `127.0.0.1` and require non-sandboxed execution if run in restricted environments).

```rust
fn device_input_channel_count(device_id: u32) -> u32 {
    let address = AudioObjectPropertyAddress {
        mSelector: kAudioDevicePropertyStreamConfiguration,
        mScope: kAudioObjectPropertyScopeInput,
        mElement: kAudioObjectPropertyElementMain,
    };
    let mut data_size: u32 = 0;
    let status = unsafe {
        AudioObjectGetPropertyDataSize(
            device_id,
            NonNull::from(&address),
            0,
            ptr::null(),
            NonNull::from(&mut data_size),
        )
    };
    if status != 0 || (data_size as usize) < size_of::<u32>() {
        return 0;
    }
    let mut buf = vec![0u8; data_size as usize];
    if let Some(buf_ptr) = NonNull::new(buf.as_mut_ptr().cast::<c_void>()) {
        let status = unsafe {
            AudioObjectGetPropertyData(
                device_id,
                NonNull::from(&address),
                0,
                ptr::null(),
                NonNull::from(&mut data_size),
                buf_ptr,
            )
        };
        if status != 0 {
            return 0;
        }
        // SAFETY: `AudioBufferList` starts with `mNumberBuffers: u32` followed by `AudioBuffer`s.
        let list = unsafe { &*(buf.as_ptr().cast::<objc2_core_audio_types::AudioBufferList>()) };
        let count = list.mNumberBuffers as usize;
        if count == 0 {
            return 0;
        }
        let buffers = unsafe { std::slice::from_raw_parts(list.mBuffers.as_ptr(), count) };
        return buffers.iter().map(|b| b.mNumberChannels).sum();
    }
    0
}

pub fn get_default_input_device() -> Option<u32> {
    let address = global_address(kAudioHardwarePropertyDefaultInputDevice);
    get_property_u32(system_object_id(), &address).filter(|&id| id != 0)
}

pub fn get_input_device_volume(device_id: u32) -> f32 {
    let virtual_vol_addr = AudioObjectPropertyAddress {
        mSelector: K_AUDIO_HARDWARE_SERVICE_DEVICE_PROPERTY_VIRTUAL_MAIN_VOLUME,
        mScope: kAudioObjectPropertyScopeInput,
        mElement: kAudioObjectPropertyElementMain,
    };
    let ch1_vol_addr = AudioObjectPropertyAddress {
        mSelector: kAudioDevicePropertyVolumeScalar,
        mScope: kAudioObjectPropertyScopeInput,
        mElement: 1,
    };
    get_property_f32(device_id, &virtual_vol_addr)
        .or_else(|| get_property_f32(device_id, &ch1_vol_addr))
        .unwrap_or(1.0)
        .clamp(0.0, 1.0)
}

pub fn get_input_device_mute(device_id: u32) -> bool {
    let mute_addr = AudioObjectPropertyAddress {
        mSelector: kAudioDevicePropertyMute,
        mScope: kAudioObjectPropertyScopeInput,
        mElement: kAudioObjectPropertyElementMain,
    };
    get_property_u32(device_id, &mute_addr)
        .map(|v| v != 0)
        .unwrap_or(false)
}

pub fn list_input_devices() -> Vec<crate::state::InputDeviceInfo> {
    let address = global_address(kAudioHardwarePropertyDevices);
    let mut data_size: u32 = 0;
    let status = unsafe {
        AudioObjectGetPropertyDataSize(
            system_object_id(),
            NonNull::from(&address),
            0,
            ptr::null(),
            NonNull::from(&mut data_size),
        )
    };
    if status != 0 || data_size == 0 {
        return Vec::new();
    }
    let count = data_size as usize / size_of::<AudioObjectID>();
    let mut device_ids = vec![0 as AudioObjectID; count];
    if let Some(out_ptr) = NonNull::new(device_ids.as_mut_ptr().cast::<c_void>()) {
        let status = unsafe {
            AudioObjectGetPropertyData(
                system_object_id(),
                NonNull::from(&address),
                0,
                ptr::null(),
                NonNull::from(&mut data_size),
                out_ptr,
            )
        };
        if status != 0 {
            return Vec::new();
        }
        device_ids.truncate(data_size as usize / size_of::<AudioObjectID>());
    }

    let default_input_id = get_default_input_device();
    let mut devices = Vec::new();
    for id in device_ids {
        if device_input_channel_count(id) == 0 {
            continue;
        }
        let Some(name) = get_device_name(id) else {
            continue;
        };
        if name.starts_with("VolumeMixer-Tap-") {
            continue;
        }
        let Some(uid) = get_device_uid(id) else {
            continue;
        };
        devices.push(crate::state::InputDeviceInfo {
            id,
            uid,
            name,
            is_default: default_input_id == Some(id),
            volume: get_input_device_volume(id),
            muted: get_input_device_mute(id),
        });
    }
    devices.sort_by(|a, b| {
        b.is_default
            .cmp(&a.is_default)
            .then_with(|| a.name.to_lowercase().cmp(&b.name.to_lowercase()))
    });
    devices
}

pub fn set_input_device_volume(device_id: u32, volume: f32) -> Result<(), String> {
    let clamped = volume.clamp(0.0, 1.0);
    let virtual_vol_addr = AudioObjectPropertyAddress {
        mSelector: K_AUDIO_HARDWARE_SERVICE_DEVICE_PROPERTY_VIRTUAL_MAIN_VOLUME,
        mScope: kAudioObjectPropertyScopeInput,
        mElement: kAudioObjectPropertyElementMain,
    };
    if has_settable_property(device_id, &virtual_vol_addr) {
        return set_f32_property(device_id, &virtual_vol_addr, clamped);
    }
    for channel in [0u32, 1u32, 2u32] {
        let ch_addr = AudioObjectPropertyAddress {
            mSelector: kAudioDevicePropertyVolumeScalar,
            mScope: kAudioObjectPropertyScopeInput,
            mElement: channel,
        };
        if has_settable_property(device_id, &ch_addr) {
            return set_f32_property(device_id, &ch_addr, clamped);
        }
    }
    Err(String::from("Input device has no settable volume property"))
}

pub fn set_input_device_mute(device_id: u32, muted: bool) -> Result<(), String> {
    let mute_addr = AudioObjectPropertyAddress {
        mSelector: kAudioDevicePropertyMute,
        mScope: kAudioObjectPropertyScopeInput,
        mElement: kAudioObjectPropertyElementMain,
    };
    set_u32_property(device_id, &mute_addr, u32::from(muted))
}

pub fn set_default_input_device(device_id: u32) -> Result<(), String> {
    let address = global_address(kAudioHardwarePropertyDefaultInputDevice);
    set_u32_property(system_object_id(), &address, device_id)
}
```

Add `DuckingTracker` to `AudioEngine`:
- Tracks `last_voice_active_at: Option<std::time::Instant>` and `is_active: bool`.
- `update(&mut self, voice_peak_active: bool, config: &AutoDuckingConfig, now: Instant) -> bool`:
  - If `!config.enabled`, reset `is_active = false`, `last_voice_active_at = None`, return `false`.
  - If `voice_peak_active`, set `last_voice_active_at = Some(now)`, `is_active = true`, return `true`.
